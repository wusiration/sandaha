# 三打哈（网页版）

一个可直接在浏览器中运行的**三打哈**扑克游戏，支持 1 名玩家与 3 个机器人 AI 对战。

## 游戏规则概要

- **牌数**：两副牌，去掉 3、4，共 92 张；8 张为底牌，每家 21 张，一局共 21 轮。
- **阵营**：1 名庄家 vs 3 名闲家。
- **常主**：大王、小王、2、7 永远是主牌。
- **主牌花色**：庄家在埋底后选择黑桃/红桃/梅花/方块为主牌，也可选择“无主”。
- **叫分**：从 80 分起叫，每次至少降 5 分，叫分最低者成为庄家（庄分即该叫分）。
- **得分牌**：5 = 5 分，10/K = 10 分。
- **胜负**：一局结束后，若闲家总得分 ≥ 庄分，庄家下庄；否则庄家获胜。
- **抠底**：最后一轮若闲家以主牌获胜，可获得底牌中的分数（对子抠底双倍，拖拉机四倍）。
- **埋底**：叫庄成功后，8 张底牌会先加入庄家手牌一起展示，庄家从中选出 8 张作为新的底牌。

## 牌型

- 单张
- 对子（同花色同点数；主牌同样必须同花色同点数）
- 拖拉机（同一花色内相邻点数的连对，如 5566、AAKK；主牌按主牌大小顺序且必须同一花色）
- 甩牌（仅首家可出，且仅限主牌；由主牌中的单张、对子、拖拉机任意组合而成，总张数 ≥ 2）

**比牌规则**：主牌大于副牌；相同牌型才比较大小。例如：单张主牌只能压单张副牌，不能压副牌对子；必须出主牌对子才能压副牌对子。

## 运行方式

直接用浏览器打开项目根目录下的 `index.html` 即可：

```bash
# Windows
start index.html

# 或者用 Python 启动本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

### 明牌调试模式

在 URL 后加上 `?cheat` 或 `?mingpai` 进入明牌模式，玩家可以看到机器人手牌：

```
index.html?cheat
index.html?mingpai=1
```

明牌模式会在页面右上角显示“👁 明牌模式”标识。

## 打包成安卓 App（Capacitor）

项目已配置 [Capacitor](https://capacitorjs.com/)，可将网页打包为安卓 APK。

### 前置要求
- 安装 [Node.js](https://nodejs.org/)
- 安装 [Android Studio](https://developer.android.com/studio)（用于构建 APK）

### 打包步骤

1. 安装依赖（已安装可跳过）：
   ```bash
   npm install
   ```

2. 同步 web 资源到安卓工程：
   ```bash
   npm run sync
   ```

3. 用 Android Studio 打开工程：
   ```bash
   npm run open:android
   ```

4. 在 Android Studio 中：
   - 连接手机或启动模拟器
   - 点击 **Build → Build Bundle(s) / APK(s) → Build APK(s)** 生成 APK
   - 或点击 **Run** 直接安装调试

### 注意事项
- 修改 `index.html` 后，必须重新执行 `npm run sync` 再打包，才会把最新内容同步到安卓工程。
- 如果需要真机调试，请在手机设置中开启“USB 调试”。

## PWA 支持

项目已配置 PWA，用支持 PWA 的浏览器打开后，可“添加到主屏幕”离线运行。

在明牌模式下，如果你不是庄家，出牌阶段会显示 **查看埋底** 按钮，点击后可查看庄家的埋底牌。

明牌模式下每位玩家信息栏还会显示该手牌的**牌力评级**（极强/强/中上/中等/偏弱/弱）以及 AI 的**建议叫分**，方便调试和观察 AI 决策。

## 操作说明

1. 点击 **新游戏** 开始。
2. 叫分阶段：选择叫分或不叫；若不想继续竞争可点击“不叫”。
3. 若你成为庄家：
   - 底牌会自动加入你的手牌，从 29 张牌中选出 8 张要埋入底牌的牌，然后点击 **确认埋底**。
   - 任何时候都可以点击 **排序** 按钮重新整理手牌。
   - 选择主牌花色或“无主”。
4. 出牌阶段：
   - 点击手牌选中（支持多选以出对子/拖拉机/甩牌），然后点击 **出牌**。
   - 甩牌仅首家可出，且仅限主牌；系统会自动判断甩牌是否最大，若不能确保最大，则自动改为出选中最小的一张牌。
   - 点击 **提示** 让 AI 帮你选择一手合法的牌。
5. 多局对战：
   - 每局结束后会弹出 **战绩板**，显示本局结果、累计庄家胜/闲家胜、闲家总得分和历史记录。
   - 点击 **下一局** 继续对战并保留战绩；点击 **重置战绩** 清空统计。
6. 记牌器：
   - 点击 **记牌器** 按钮打开/关闭辅助面板。
   - 实时显示总剩余张数、主牌剩余张数、各花色剩余张数、剩余 A/K 数量以及哪些玩家已缺某门花色。
7. 音效与动画：
   - 发牌、叫分、出牌、赢墩、抠底、结算均有音效。
   - 出牌有弹入动画，赢墩有脉冲放大和收牌动画。

## 备注

- 机器人 AI 采用基于牌力与角色（庄家/闲家）的启发式策略，会自动叫分、埋底、选主、出牌与跟牌。
- AI 已具备基础**记牌能力**（跟踪已出主牌、副牌缺门、剩余大牌），并会据此调整出牌：庄家优先攻击对手缺门花色，闲家之间会避免压过同伴、在队友明显大时主动上分、尽量减少给对手送分。
- AI 叫分不仅看单张大牌，更重视**对子/拖拉机结构**，对子越多叫分越积极。
- 游戏完全离线运行，无需联网或安装依赖。
